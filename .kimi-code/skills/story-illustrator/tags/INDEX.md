## 查询纪律

- 一次 Grep 一个概念,优先中文词,其次英文 tag 词根(如 `thighhigh`、`bondage`)
- 查到标签后**原样使用**库中的英文写法,不要自行改写
- 库里没有的概念 → 用自然语言短句写在 prompt 末尾,**不伪造 tag**
