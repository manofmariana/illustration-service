# 16. 补充标签(来自 ST 预设实证)

> 来源:SillyTavern 生图预设内置词表,挑本库原先缺失的三个小类,轻量补充。

## 16.1 界面/屏幕元素(「屏中屏」梗)

| 概念 | tag | 用法 |
|---|---|---|
| RPG 游戏界面 | `rpg game interface` | 游戏穿越/系统流 |
| 状态面板 | `status screen` | 属性弹窗悬浮 |
| 好感/兴奋度条 | `arousal meter` | 调教/堕落进度可视化 |
| 聊天记录界面 | `chat log` | 手机聊天/NTR 截图感 |
| 伪截图 | `fake screenshot` | 社交软件/直播界面整体伪装 |
| 直播界面 | `livestream` | 主播/弹幕场景 |
| 自拍 | `selfie` | 对镜/手机自拍视角 |
| 照片(画中之物) | `photo (object)` | 手持照片/遗照/纪念照 |
| 手机屏幕 | `phone screen` | 视频通话/偷拍画面 |
