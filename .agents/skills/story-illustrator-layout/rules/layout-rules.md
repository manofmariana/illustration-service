## 版式设计细则

### 1. 先定版面骨架,再放框

| 骨架 | 适用 | 框的分布 |
|---|---|---|
| 中心式 | 单人立绘、头像、封面 | 主体框居中占 50–70% 高度,其余星散四周 |
| 三分式 | 场景插图 | 主体压在左或右三分线上,空旷处放文字 |
| 上下分区 | 海报、封面、标题图 | 上 1/3 标题区,中 1/2 主体区,下 1/5 落款区 |
| 左右分区 | 横版招牌、对比、多格 | 左文右图或左图右文 |
| 屏中屏 | 手机屏、监视器、窗外 | 外层场景框 + 内层屏幕框,内层文字再单独成框 |

### 2. 安全边距

四周留 **5% 边距**:1024 宽留 51px,1536 高留 77px。标题不要贴边,文字不要压到画面最外沿——模型对边缘文字的处理明显更差。

### 3. 层级与字号(按画布换算)

| 层级 | 占画布宽 | 1024 宽时 | 一行字数 |
|---|---|---|---|
| 主标题 | 50–80% | 510–820px | 中文 4–8 字 / 英文 2–5 词 |
| 副标题 | 35–55% | 360–560px | 中文 8–14 字 |
| 正文/说明 | 25–40% | 250–410px | 中文 10–18 字,可多行 |
| 小字/标签 | 15–25% | 150–250px | 中文 4–8 字 |

**字数估算**:中文一个字约占字号的 1 个方块。一个宽 400px、字号 60px 的框,一行约 6 个字,两行 12 个字。**先算能不能放下,再写框。**

### 4. 阅读顺序

- 中文/英文横排:从上到下、从左到右。
- 需要强调先后时,用 `bbox` 的 y 值拉开层级,而不是靠 caption 里写"第一个"。
- 竖排中文(招牌、书脊、条幅):一个 text 框,`text` 里用 `\n` 分隔每个字,或整句竖排描述。

### 5. 常见场景的具体版式

**手机屏 / 聊天界面**
- 外层一个 `object` 框画手机或整个屏幕
- 屏幕内:每个气泡一个 `text` 框,左右分开(发送方靠右、接收方靠左)
- caption 写清 UI 风格(深色模式、圆角气泡、时间戳小字)但**不要**给每个 UI 元素都开框

**对白气泡 / 漫画框**
- 气泡本身算 `object` 框(写形状:圆形、云朵、锯齿)
- 气泡里的字算 `text` 框,框在气泡内且略小于气泡
- 说话人指向:caption 里写"气泡的尾巴指向她"

**海报 / 封面**
- 主标题、副标题、落款各一个 `text` 框,纵向排开
- 主视觉一个 `character` 或 `object` 框
- 背景氛围写进 `summary.caption`,不开框

**招牌 / 店招 / 路牌**
- 招牌底板 `object`,字 `text`
- 字要按实际阅读方向排;竖招 `text` 用 `\n` 逐字分行

**书页 / 便签 / 日记**
- 纸张 `object`,标题与正文各一个 `text` 框
- 正文框内的字不要写满,写 2–3 行就够,写太满会糊

**多格分镜**
- 仅在用户明确要求时用,`summary.canvas` 设 `multi_panel`
- 每格一个 `object` 框描述该格内容,格内文字再单独开框
- 格与格之间留 2–4% 间隙

### 6. 几何自检清单(提交前逐项过)

1. `width` / `height` 是 16 的倍数?
2. `width`×`height` 对应 `<size>`,两者字符串完全一致?
3. 总像素是否落在 1M / 1.5M / 2M 附近(0.8M–2.2M 可接受)?
4. 每个 `bbox` 都是 4 个**整数**,且 `0 ≤ x1 < x2 ≤ width`、`0 ≤ y1 < y2 ≤ height`?
5. 有没有框越界或退化成一条线(x1==x2 或 y1==y2)?
6. 框数量在 3–12 之间?
7. 每个框的 `caption` 都非空,且只描述**这个框里**看得见的东西?
8. 所有 `label=text` 的项都带 `text`,且是原语言原文(不是翻译、不是占位符)?
9. 文字框的宽高够不够容纳它的字数(按 §3 字号表估)?
10. 有无重到完全相同的框(位置和内容都相同)?有就删掉一个。
11. `summary.caption` 是英文、60–160 词、且不与某个 item 的 caption 逐字重复?
12. JSON 里没有 `children` / `parent` / `id` / `elements` 等禁用字段?
13. 坐标写的是**左上原点 xyxy**?(居中、yxyx 由服务端换算,不要自己算)
14. 每段文字的 `caption` 有没有交代阅读顺序、对齐、大小层级、字体、颜色、间距?

### 7. 排版失败时的降级顺序

1. 先**减字**:删掉非关键的文字框。
2. 再**放大框**:给文字更多空间。
3. 再**换画布**:竖版挤不下就换横版(`1536x1024`)。
4. 最后才**减少框数**:合并相邻元素为一个框。

**永远不要**为了硬塞文字而把框做得比字还小——那一定糊。
