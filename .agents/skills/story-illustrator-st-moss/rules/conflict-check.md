## 3. 提交前自检

caption 写完后,逐项打勾,有冲突回退修改:

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | **人数一致** | 文字里出现的人数、性别与素材一致,没有"一个女人"却另有"他的手"这种凭空多出的人 |
| 2 | **事实互斥** | 对照 §3.1 互斥表,无视角/身份/服装/动作/光照矛盾 |
| 3 | **不重复** | 同一个短语不在两处逐字出现(下行会按逗号分段去重,重复段会被删) |
| 4 | **物理合理** | 动作与场景兼容(水下不点烟、床上不站军姿),接触点有可见对象 |
| 5 | **光影一致** | 恰有一处明确光源,方向与时辰、情绪一致 |
| 6 | **遮挡一致** | 视角/姿势导致某部位不可见时,不写该部位的细节(俯视只见背就别写"她的眼睛";低头掩面就别写笑容) |
| 7 | **词数与形态** | 80–200 词(文字多可到 260),单段无换行,英文散文 |
| 8 | **传输安全** | 无 `$`、无全角括号、无 `Scene Composition` 字面、无 `¦`、无换行 |
| 9 | **禁物** | 无质量词、无权重语法、无画师名、无负向提示词、无下划线 tag |
| 10 | **画面文字** | 可见文字原样引用且未翻译;不必须的字就不要画 |

**自检流程**:写完 → 逐项打勾 → 有冲突就改 → 全过才提交。

## 3.1 事实互斥表

以下组合写在同一张图里物理或逻辑矛盾,必须二选一:

### 视角互斥

| A | B | 原因 |
|---|---|---|
| `from the front` | `from behind` | 物理矛盾 |
| `from above` | `from below` | 物理矛盾 |
| `looking at the viewer` | `looking away` | 视线矛盾 |
| `first-person view` | `full body`(指主体全身) | 第一人称看不到自己全身 |
| `close-up` | `full body` | 景别矛盾 |

### 身份互斥

| A | B | 原因 |
|---|---|---|
| 独自一人 | 出现第二个人体的动作 | 单人不存在互动 |
| 女性支配 | 女性被强迫 | 主导方冲突 |
| 睡着/失去意识 | 直视观者 | 无意识不可能直视 |
| 蒙眼 | 眼神描写(瞳孔、翻眼、对视) | 看不到眼睛 |

### 服装互斥

| A | B | 原因 |
|---|---|---|
| 全裸 | 任何具体服装 | 全裸不穿衣 |
| 连裤袜/丝袜 | 光脚 | 除非写明丝袜被撕开 |
| 蒙眼 | 戴眼镜 | 物理冲突 |
| 完整内衣套装 | 没穿内裤/下半身裸露 | 套装隐含含内裤;需要暴露就写单件 |

> **不互斥**:外衣/制服(女仆装、校服、兔女郎装)与"没穿内裤"完全兼容。

### 动作互斥

| A | B | 原因 |
|---|---|---|
| 站立性交 | 躺着/仰卧 | 体位矛盾 |
| 传教士 | 后入 | 不能同时两个体位 |
| 女上位 | 趴伏后入 | 体位矛盾 |
| 口交 | 舔阴(同一人执行) | 嘴只有一张 |

### 细节过度

同一身体部位同时写多个状态会让模型过度渲染、画畸形。**每部位状态 ≤2 个,且不能互斥。**

| 部位 | 矛盾组合 |
|---|---|
| 脚趾 | 张开 vs 蜷缩;张开 vs 双脚并拢 |
| 手指 | 张开 vs 握拳/抓握 |
| 胸部 | 晃动 vs 挤压 |
| 嘴 | 张嘴 vs 咬牙/闭嘴 |
| 眼睛 | 翻白眼 vs 直视 |
| 腿 | 分开 vs 并拢 |
| 足部整体 | 3 个以上足部细节叠加 |

**原则**:状态可以多,但必须同一状态;`光脚 + 脚部特写 + 足底 + 蜷趾` 四个兼容没问题,`张开脚趾 + 蜷缩脚趾` 两个就矛盾。

**例外**:丝袜撕开处露出脚、半脱状态 + 具体服装,都是合理的。

### 散文专属:易写崩的三种句子

| 坏写法 | 问题 | 改法 |
|---|---|---|
| `she smiles as he smiles, both smiling` | 重复段会被下游删掉 | 换词或合并成一句 |
| `the girl looks at the boy and he looks at her` | 双向对视写两遍冗余 | 一句 `they hold each other's gaze` |
| `a cup, a book, a lamp, a chair, a window, a rug` | 物件罗列变成 tag 串 | 只留 1~2 个有叙事作用的 |
