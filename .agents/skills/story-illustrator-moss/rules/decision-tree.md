## 5. 选景决策树(ASSEMBLY DECISION TREE)

> 拿到需求先在本章匹配场景类型,取得**这张图必须写进 caption 的可见要素**与机位推荐,再跳 §4 写句子。特殊主题类必须先查 `tags/14`。

### 5.1 单人展示类(诱惑/暴露/自慰/展示自拍)

| 必写要素 | 内容 |
|---|---|
| 主体 | 一个人 + 唯一动作 |
| 外观 | 头发2项 + 眼睛1项 + 体型 + 肤色 |
| 服装 | 1~2 件核心服装 + 1 个状态(半脱/湿透/全裸+配饰),状态不超过 2 层 |
| 表情 | 诱惑默认克制(微红/半垂眼),不要一上来就高潮脸 |
| 机位 | 全身展示 `full body, from the front` · 诱惑 `framed from the thighs up` · 自慰 `from above` · 暴露 `from outside through the window` |
| 场景 | 主场所 + 1 个环境锚点(简约可用"室内、纯色墙") |

### 5.2 双人前戏类(口交/足交/素股/手交/乳交/调戏)

| 必写要素 | 内容 |
|---|---|
| 人数与性别 | 一男一女,关系一句话讲清 |
| 外观 | 女方≥3 锚点;男方精简(发色+体型或"衣着整齐") |
| 接触点 | **必须写清身体接触的具体部位与方式** |
| 表情 | 克制的愉悦/紧张,除非素材强制深喉/过激 |
| 机位 | 口交 `from above, first-person` · 足交 `from the side, feet in frame` · 乳交 `close-up` · 调戏 `framed from the thighs up` |
| 场景 | 与前戏类型配套:桌下→餐桌;足交→沙发/卧室;调戏→电车/办公室 |

### 5.3 双人正戏类(传教士/站立/坐位/后入/火车便当/种付/骑乘)

| 必写要素 | 内容 |
|---|---|
| 人数与性别 | 一男一女,有体型差就写 |
| 女方服装状态 | 这是画面核心:半脱/掀起/全裸/破损/湿透,选 1~2 层 |
| 体位 | 写清**身体如何交叠、谁在上谁在下、腿在哪** |
| 表情 | 中等强度为主,冲刺阶段可更强 |
| 机位 | 传教士 `from above` · 后入 `from behind, seen from above` · 骑乘 `from below` · 种付 `from above, close` |
| 场景 | 主场所 + 1 个道具;按场景风险等级选(卧室/浴室/教室/电车) |
| 细节 | 1 个动态线索(汗、晃动、抓握)+ 氛围 |

### 5.4 特殊体位类(睡奸/催眠/攻守反转/过激)

| 类型 | 额外必写 |
|---|---|
| 睡奸 | 女方 `asleep, eyes closed, breathing evenly`;**禁止写"看向观者"**;环境补"被子/暗室"增强隐蔽 |
| 催眠 | 眼神空洞、表情空白;可写她执行被命令的动作;可写"手机屏幕上的催眠图案" |
| 攻守反转 | 女方主动/支配(皮衣、居高临下),男方退缩、颤抖 |
| 过激 | 强度拉满,必须写≥1 个身体反应;光线压暗 |

### 5.5 多人/群交类

| 必写要素 | 内容 |
|---|---|
| 人数 | **精确**写几个男人几个女人 |
| 外观 | 每个角色≥3 锚点防串脸;背景男性可简化为"几个看不清脸的男人" |
| 占用 | 写清哪个部位被占用、几个人在动作 |
| 机位 | 3 人优先第一人称视角(男性只露手/胯/腿);全景则 `from above` |
| 场景 | 大空间 + 人群感(`surrounded by`, `crowd`) |

> 本服务全局上限 3 人。4 人及以上剧情一律改选其中 1~2 人特写,并在 caption 里用"周围还有人"暗示,不要真的画 4 个人。

### 5.6 百合类

| 必写要素 | 内容 |
|---|---|
| 人数 | 两个女性,关系一句话 |
| 互动 | 写清谁主动、接触部位、两人的表情差异 |
| 机位 | `from the side` 展示互动;骑乘式 `from above` |

### 5.7 特殊主题类(NTR/BDSM/男娘Futa/异种/调教/胁迫/偷窥/事后/另类日常/大车小孩/隐奸)

> 跨槽位场景。**先查 `tags/14` 对应小节**取配方,再套 5.1–5.6 中最接近的基础类型。

| 特殊主题 | 基础模板 | 核心差异(写进 caption 的部分) |
|---|---|---|
| NTR | 5.3 | 加"隔门/窗外/手机另一头有人"的视线结构 |
| 束缚/BDSM | 5.3 | 绳索走向、束缚姿势、勒痕、用具 |
| RBQ/物化 | 5.5 | 物化标记、过量体液、失神状态 |
| 男娘/Futa | 5.3 | 换掉人数与外观体系 |
| 异种 | 5.3 | 非人男方 + 特殊体位 |
| 调教/宠物 | 5.1 | 项圈、爬行、食盆、服从表情 |
| 胁迫 | 5.2/5.3 | 权力关系 + 抗拒到屈服的过渡 |
| 偷窥/展示 | 5.1 | 偷看视角 / 隐藏摄像头 / 自拍构图 |
| 事后 | 5.1/5.3 | **无性行为**,重残留(凌乱床单、汗、红痕)与情绪余韵 |
| 另类日常 | 5.1/5.3 | 表情自然平淡,场景日常 |
| 大车小孩 | 5.3 | 体型差与年龄感(成年女性+少年) |
| 隐奸 | 5.2/5.3 | 头部在画外 / 被子下 / 只用暗示 |

### 5.8 带文字的场景(小说插图高频)

若画面里有**必须可读的文字**(对白框、手机屏、招牌、书页、便签、弹幕):

1. 先判断这段文字**是否必须入画**。不是关键剧情就不画字,省得画错。
2. 必须入画时,按 §3.3 原样引用,并写清位置与字体气质。
3. 文字多(超过 2~3 行)→ 优先改用 `<size>` 里更宽的横构图,给字留空间。
4. **不要**把中文台词翻译成英文再引用。
